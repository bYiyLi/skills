Assessment reads actual artifacts, file changes, commands and outputs, not just
exit status. New behavior claims require observed reads/results; static graph
checks cannot establish conditional model loading. A passing trial does not
prove reliability across all models or hosts. Preserve failures and rerun only
affected cases after corrections.
