# ChatGPT plugin integration

This package contains nexum-chatgpt-development only. For software engineering,
discover development-standards:develop-software in the host and read its entrypoint
and selected references. Load the other general authoring Skills when required
by the task. Do not assume plugin installation installs its dependencies.
Missing or unreadable mandatory guidance blocks dependent engineering only;
connection diagnosis and raw status inspection can proceed within authority.
Report the missing source; do not reconstruct it or install another plugin without
authorization. If multiple copies exist, prefer the named development-standards
plugin; do not choose an arbitrary same-name copy.

Use each discovered package's actual resource locator, not a guessed sibling
filesystem path. Plugin resources belong to the host, not the Nexum Agent.
Installing this plugin does not install Skills on an Agent, and project.open
does not refresh ChatGPT plugin discovery. Agent-side installation described in
project-setup applies only when separately requested.

The distribution package has no private app binding. Reuse the user's connected,
authorized Nexum app when available. An optional account-specific binding may be
generated from a verified app ID. Missing tools or denied access block their
operations, not unrelated text-only work. Do not register duplicate connections.
Host execution restrictions and user approvals remain in force.
