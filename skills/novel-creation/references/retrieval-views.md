# Retrieval Views

`retrieve text`

- 搜所有 scene、chapter、volume、source、WORK 文本。

`retrieve source`

- 搜 `设定/` 与 `角色/` 真源。

`retrieve scene|chapter|volume|work`

- 只在对应记录类型里搜索。

`report context-pack --profile draft`

- 强调 scene 当前目标、相关真源和 continuity refs。

`report context-pack --profile check`

- 强调 blockers、冲突候选和需要回流的点。

`report context-pack --profile archive`

- 强调 ready frontier、当前卷与当前章。

`report context-pack --profile handoff`

- 强调 stage、blockers、next step 和 reentry scene。
