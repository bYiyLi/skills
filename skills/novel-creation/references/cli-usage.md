# CLI Usage

主链路命令：

- `novelctl init <workspace>`
- `novelctl sync <workspace>`
- `novelctl status <workspace>`
- `novelctl check <workspace>`
- `novelctl retrieve <mode> <workspace> [query]`
- `novelctl report <report> <workspace>`
- `novelctl archive chapter <workspace>`
- `novelctl archive volume <workspace>`

常用检索模式：

- `text`
- `scene`
- `chapter`
- `volume`
- `source`
- `work`
- `unresolved`
- `conflict-candidates`

常用 report：

- `summary`
- `gates`
- `conflicts`
- `unresolved`
- `freshness`
- `context-pack --scene <scene_id> --profile draft|check|archive|handoff`
