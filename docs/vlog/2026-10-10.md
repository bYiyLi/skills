### 评审与修正

共完成5次独立只读审阅，使用 Mac Codex CLI 0.158.0 / gpt-6-sol high。先覆盖全部运行包、
原专业合同、模板和测试迁移，再针对变更继续检查；后续修改只重审受影响路径。

| 发现 | 实际修正与证据 |
| --- | --- |
| Nexum 仅在通用 Skill 已选中时才加载，缺少真正的进入条件 | 主入口与独立 Project Instructions 明确软件任务读取通用包，工作区-only 例外保留 |
| 已有日志的实现路径与只读返回聊天规则有歧义 | 明确实现的 existing/setup/request 条件和只读例外；实际修复写新日志，只读评审保持历史不变 |
| 缺 UI/文档时仍要求具体步骤，且 evidence 分支有 and/or 冲突 | 按可访问的官方文档和可观察 UI 分别限定声明；两者都缺失时保留步骤未验证 |
| 模板将草案称为已部署的 UI 副本 | 仅当维护源和已保存 UI 副本都存在时才描述部署关系，否则报告待完成 |
| 一次生成试跑读取模板却遗漏通用开发加载条件 | 增加输出合同保留检查，用相同原始请求复测；最后草案保留加载、范围和未保存状态 |
| 无 Git 的任务被无条件 staged/untracked 检查阻塞 | 主入口、verification 和独立 AGENTS 使用条件化 Git 检查；无 Git 比较可用原始证据并报告限制，不为验收初始化 Git |

最后一次通用变更复审无剩余可操作发现；未再变动的 Nexum 路径已在此前复审确认。
这是累计覆盖的文本结论，不是任意输入下零缺陷保证。
